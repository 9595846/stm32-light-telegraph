# 接线与光路布置

当前设计不要求改 GPIO 接线。接线前断电；器件引脚按模块标识和用户已确认的线序判断。

图示见同目录 `接线图.png` 和 `接线图.svg`。它是按引脚名称连接的端子图，不代表最小系统板的实际排针排列。本阶段舵机保持关闭，首次验证可不给舵机供电。

| 器件 | 怎么接 |
|---|---|
| OLED | GND 接公共 GND，VCC 接 3.3V，SCL 接 PB10，SDA 接 PB11 |
| IMU | GND、AD0 接 GND，VCC 接 3.3V，SCL 接 PB6，SDA 接 PB7；PB6、PB7 保留现有各一只 10kΩ 上拉到 3.3V |
| 光敏 | GND 接 GND，VCC 接 3.3V，AO 接 PA1，DO 留空 |
| 编码器 | A/CLK 接 PA6，B/DT 接 PA7，公共端接 GND；如有 VCC 接 3.3V，按压 SW 暂不接 |
| KEY1 | PB12 与 GND 之间，使用按下才导通的一对有效触点 |
| KEY2 | PB15 与 GND 之间 |
| KEY3 | PB8 与 GND 之间 |
| KEY4 | PB9 与 GND 之间 |
| 蜂鸣器 | I/O 接 PB14，VCC 接 3.3V，GND 接 GND；沿用低电平触发 |
| LED1 | PA0 → 独立 1kΩ 电阻 → LED 阳极，LED 阴极接 GND |
| LED2 | PB0 → 独立 1kΩ 电阻 → LED 阳极，LED 阴极接 GND |
| SG90 | 信号接 PA8，正极接独立 5V，负极接独立电源 GND；独立电源 GND 与 STM32 GND 相连 |
| USB 转串口 | RXD 接 PA9，TXD 接 PA10，GND 接 GND；使用 3.3V 逻辑，电源脚留空 |
| ST-Link | 专用 SWD 接口接 SWDIO、SWCLK；GND 接 GND；沿用已确认的 3.3V 供电接法，整套负载余量待实测 |

两颗 LED 各用一只限流电阻。若只有一只 1kΩ，优先给发射灯，另一灯可先用 10kΩ 并接受其可能较暗；现有灯已串联电阻时不要重复误接。独立 5V 不接 STM32 的 3.3V。

OLED 的 PB10/PB11 是否另加上拉，应先检查模块板载电路。OLED 与 IMU 是两条独立 I²C 总线。

目前基础代码中编码器使用 TIM3，舵机使用 TIM1，光敏使用 ADC1，串口使用 USART1；未发现上述信号引脚重复占用。新固件完成后仍需核对其初始化和定时器配置。

## 光路布置

正式版：LED1 对准光敏元件，中间留出纸片遮光的位置。先从近距离尝试，距离由实测决定。用不透光纸筒减少周围光干扰，不能挡住灯到光敏元件的通路。

舵机固定在旁边，用轻纸片伸入或移出光路。先手持纸片确认遮挡有效，再空载标定舵机，不先安装紧绷连杆或让纸片顶住结构。

舵机正负极以用户已经调通的线序为准，不凭颜色判断。现有基础代码仅允许 1400～1600μs，不能直接当作已确认的开、关位置。
